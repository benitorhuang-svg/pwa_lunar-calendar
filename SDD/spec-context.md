# 農民曆 PWA - 規格與設計文件 (Spec Context)

## 1. 產品定位與目標
**「時間的藝術品」**：本產品旨在將傳統的農民曆數位化，轉變為一個具備「沉浸式」、「質感導向」的視聽體驗應用。

## 2. 核心功能規格 (Functional Specifications)

### 2.1 導航與交互模態 (Interaction Modes)
應用程式具備三種核心模態：
1.  **歡迎模式 (Welcome Mode)**：啟動時顯示今日宜忌，具備莊嚴的儀式感。
2.  **操作模式 (Interface Mode)**：顯示日曆網格、年月選擇器等 UI 控制元件。
3.  **映畫模式 (Artwork Mode)**：閒置 5 秒後觸發，UI 消失，僅保留高畫質背景與背景音樂。

### 2.2 智能儀式啟動流 (Centric Utility Flow)
*   **啟動序列**：資源讀取中 -> 首張美圖渲染 -> 顯示今日宜忌卡片 (WelcomeOverlay)。
*   **自動轉場**：若啟動後無操作，5 秒後宜忌卡片淡出，進入「映畫模式」。
*   **交互路徑 A (效率)**：從歡迎模式操作底部導航，直接呼出日曆網格。
*   **交互路徑 B (觀賞)**：在映畫模式下隨處點擊，喚醒極簡控制列而非日曆，保持觀賞體驗。

### 2.3 日曆計算與數據整合
*   **傳統數據**：整合農曆、二十四節氣、天干地支、生肖、建除十二神、宜忌、今日吉時。
*   **數據來源**：本地 `lunar-core.js` (基於 lunar-javascript 算法)。
*   **跨月處理**：日曆網格中顯示的前後月灰色單元格，點選後會自動跨月跳轉。

### 2.4 主題與季節系統 (Theme Engine)
*   **動態主題**：根據目前月份及特定節慶自動切換系統主題色（Spring, Summer, Autumn, Winter, Festive, Dark, Light）。
*   **視覺變數**：主題影響背景混色比例、單元格強調色、以及字體色彩。

### 2.5 沉浸模式 (Immersion Mode)
- **映畫模式 (沉浸式)**：閒置偵測觸發全清爽、無 UI 的環境顯示模式。
- **閒置超時**：預設為 6 秒無操作。
- **自動轉場**：歡迎儀式與沉浸模式轉場現在遵循 6 秒律動，以達到最佳視覺賞析效果。

## 3. UI 元件詳述 (Component Detailed Spec)

### 3.1 Hero 區域 (Hero Section)
*   **HeroBackground**：處理 4K 畫質圖片，支援「緩慢推進」動畫效果，營造動態攝影感。
*   **HeroHeader**：極簡顯示西元年月日，透明度隨模態切換。
*   **HeroDock**：膠囊狀底部導航，採用 [步進] [入口] | [中間槽位] | [入口] [步進] 的對稱佈局。
    - **模態意識 (Mode Awareness)**：步進鍵 `< >` 會根據應用程式模式切換功能（日曆模式→換月；映畫模式→換圖）。
    - **動態槽位**：中間區域根據模式切換顯示 [年月] 圖標或 [藝廊] 功能組。

### 3.2 日曆區域 (Calendar Board)
*   **週首標題**：傳統漢字標註（日一二三四五六）。
*   **日期格 (Day Cell)**：
    - 西曆大數字位於左上。
    - 農曆日期或節氣標註位於右下。
    - 節慶、節氣字體變色強調（Festive Red, Term Gold）。
*   **狀態標記**：具備「今日 (Today)」與「選取 (Selected)」的視覺區隔。

### 3.3 面板系統 (Suspension Panels)
*   **年月面板**：網格狀選取，點擊後觸發 `year-selected` 與 `month-selected` 全域同步。
*   **今日詳情**：垂直排版，側邊欄條狀裝飾，顯示宜忌詳情貼紙 (Tags)。

## 4. 媒體與環境 (Media & Ambience)
*   **音樂管理 (Music Management)**：
    *   **預設曲目**：內建禪意環境音與線上療癒電台 (如 SomaFM, VPR Classical)。
    *   **自訂電台 (Custom Radio)**：
        - 支援使用者輸入 HTTPS 串流網址新增電台。
        - **本地儲存 (Persistence)**：自訂電台清單透過 IndexedDB 本地儲存，刷新後保留。
        - **管理功能**：支援刪除既有電台 (包含預設與自訂)。
        - **防呆機制**：點擊既有電台僅切換播放，輸入新網址才執行新增動作。
*   **安全傳輸 (Secure Stream)**：
    - 強制使用 HTTPS 協定，確保音訊串流不觸發瀏覽器的混合內容警告。
*   **音量淡入 (Fade-in)**：音樂開始播放時具備微秒級淡入，避免突兀。

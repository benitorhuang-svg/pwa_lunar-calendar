# UI/UX Design Context (SDD)

## 1. 視覺設計與美學 (Visual Aesthetics)

### 1.1 設計核心：數位 (Digital Premium)

本專案不將農曆視為過時工具，而是將其定位為「具備當代美感的文化載體」。

- **關鍵詞**：沉浸 (Immersion)、輕盈 (Leanness)、層次 (Depth)。

### 1.2 視覺技法規範

- **玻璃擬態 (Glassmorphism)**：
    - 面板背景：使用主題變數 `var(--cal-bg)`。
    - 效果：統一使用 `backdrop-filter: blur(20px) saturate(120%)`。
    - 邊界：`1px solid rgba(255, 255, 255, 0.08)`，追求極致細膩與輕盈。
- **行動優先 (Mobile First)**：
    - 核心選擇器（年月）採用「底部分頁 (Bottom Sheet)」模式，確保單手操作的便利性。
    - **工具列 (Dock) 效能最大化**：
        - 採用「側翼文字、中央符號」策略。關鍵入口（映畫、日曆）保留文字說明，頻繁切換的中間槽位（年月/藝廊）轉向圖標化驅動，為小螢幕節省 30% 以上的橫向空間。
- **材質應用 (Texture)**：
    - 全域覆蓋微量「數位噪點 (Noise Texture)」，模擬宣紙或噴砂玻璃的物理質感。
- **動態優先 (Motion First)**：
    - **曲線**：主要使用快出慢入的 `cubic-bezier(0.2, 0.8, 0.2, 1)`（通用）。
    - **方向性**：功能面板優先遵循「由下往上 (Bottom-to-Top)」的自然物理慣性，簡化過度設計的縮放彈出。
    - **呼吸感**：日曆邊框具備緩慢的 `breathe-glow` 動畫 (週期 8s)，象徵時間的流動。
    - **整體浮現 (Unified Emerge)**：資訊卡片（宜忌資訊）與外框同步執行模糊與透明度過渡。

### 1.3 轉場節奏：禪意律動 (Zen Rhythm)

本專案不追求極速，而是追求「符合心理預期的自然呼吸」：

- **閒置監控 (Idle Timer)**：6 秒。專注於畫面**未被觸碰 (Touch/Click)** 的時間，不追蹤滑鼠移動 (Ignore Mousemove)，確保給予閱讀充足視覺停留且不因誤觸滑鼠而中斷沈浸感。
- **歡迎卡片浮現**：2.2 秒。長時長過渡有助於消除技術性緊張感。
- **背景切換間隔**：6 秒。在沉浸模式下維持穩定的視覺變化頻率。

### 1.4 無縫接力 (Seamless Handover)

載入完成後，「加載遮罩溶解」與「歡迎卡片浮現」為**零時差同步啟動**。卡片內容在遮罩還殘留朦朧感時即在後方升起，確保視覺連貫性。

## 2. 空間與排版 (Space & Typography)

### 2.1 Z-Index 管理分層

專案採用變數化的 Z 軸管理，由低至高為：

1.  `--z-index-hero-bg` (0)：背景圖。
2.  `--z-index-base` (1)：主體內容。
3.  `--z-index-calendar-grid` (50)：日曆網格。
4.  `--z-index-dock` (100)：底部控制列。
5.  `--z-index-panel-overlay` (1000)：暗轉遮罩。
6.  `--z-index-panel` (1100)：彈出面板。
7.  `--z-index-loading` (10000)：首屏加載層。

### 2.2 雙重語重心長 (Typography System)

- **主體 (Display)**：`Playfair Display` + `Noto Serif TC`。
    - 襯線體的選用是與現代平面設計的「無襯線 (Sans)」做出區隔。
    - **頁首標題 (Magazine Header)**：背景框採用 45% 不透明度加強對比，文字輔以 `Year/Month/Day` 標籤，確保在複雜背景下具備雜誌級的可讀性。
- **數字 (Numeric)**：在日曆中保持 `Playfair Display` 的纖細與優雅。

## 3. 互動微體驗 (Micro-interactions)

### 3.1 視覺反饋

- **點擊效果**：日曆格與功能按鈕在按下時，應具備輕微的 `scale(0.96)` 與 `box-shadow` 減弱，模擬真實物理按下。
- **懸停狀態**：滑鼠移入時，背景發光區域擴大，展現互動的靈敏度。

### 3.2 智能焦點管理

- 當選取月份後，面板延遲 200ms 關閉，提供使用者「確認選中」的短暫視覺停留。

### 3.3 聽覺回饋 (Audio UI)

- **漸變轉場 (Crossfade)**：所有音訊切換（播放/暫停/下一首）均需實作 1000ms 以上的 `Logarithmic Fade`，模仿高階音響的阻尼感。
- **視覺連動 (Pulse Visual)**：當音樂播放時，對應的電台項目應有微弱的呼吸燈或波紋效果，讓「聽覺」具備「視覺索引」。
- **記憶偏好 (Persistence)**：系統必須記住使用者最後新增與收聽的電台，這是對使用者品味的最高尊重。

## 4. 無障礙與包容性 (A11y)

- **色彩對比**：確保農曆日期文字在各主題色下皆符合 WCAG AA 級對比標準（≥ 4.5:1）。
- **觸控區域**：所有可點擊元件（按鈕、日期格）最小觸控面積不低於 `44x44px`。
- **語義標誌**：自定義按鈕具備 `role="button"` 及 `aria-label`，確保螢幕閱讀器能理解操作意圖。

## 5. 職人精神：功能色系歸屬感 (Functional Symbiosis)

本專案追求的是超越工具之上的視覺心理引導，其靈魂在於「模式、功能、色彩」的三位一體同步：

- **日曆模式 (Gold Theme)**：
    - 當處於日曆操作模態時，導覽鍵 `< >`、年月按鈕、甚至右上角的音樂律動光芒，統一同步為**「香檳金」**系。這代表了傳統文化的厚度與時間的沉穩，指示當前的 `< >` 功能為「月份步進」。
- **映畫模式 (Silver Theme)**：
    - 一旦切換至映畫沉浸模式，全域色系瞬間轉變為**「銀白色」**。這代表了攝影藝術的純淨與光影的輕盈，指示當前的 `< >` 功能同步轉向為「影像切換」。
- **動態共生 (Dynamic Oneness)**：
    - 這種無縫的色彩與功能同步，不僅是視覺驚喜，更能顯著降低使用者的認知負擔（Cognitive Load），讓配色成為最直觀的交互語言。

## 6. 隨筆記錄 (Zen Notes)

- **入口**：右上角音樂控制下方，新增「墨水筆 (Ink Pen)」圖標。
- **介面**：
    - 點擊後喚起全螢幕「白色磨砂玻璃 (White Frosted Glass)」底稿。
    - 不透明度與模糊度需足以區隔背景但保留通透感 (`opacity: 0.85`, `backdrop-filter: blur(15px)`).
- **互動邏輯**：
    - **打破沉浸**：開啟筆記時，系統**暫停**進入全沉浸模式 (UI 不隱藏)，但背景映畫仍持續輪播 (`isImmersion: false`, `slideshow: active`)。
    - **閒置逾時**：全域閒置時間延長至 **15秒**。
- **功能**：
    - **多字體支援**：提供多種開源手寫/襯線字體供選擇。
    - **歸檔**：預設存入「今日」，亦可指定日期 (Date Picker)。
    - **匯出**：
        - 單篇：卡片式輸出 (含當前背景)。
        - 批次：純文字 (.txt) 匯出。
